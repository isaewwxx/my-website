Choose your preferred framework and follow the setup instructions below.

## ⚛️ React Portfolio Setup

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Navigate to React project
cd react-portfolio

# Install dependencies
npm install
# or
yarn install

# Start development server
npm start
# or
yarn start
```

The React application will be available at `http://localhost:3000`

## 🛠️ Development

### Adding New Components (React)

1. Create component file in `src/components/`
2. Import and use in `App.js`
3. Follow existing styling patterns
4. Use Tailwind CSS classes consistently

### Customization

1. **Colors**: Modify `tailwind.config.js` color palette
2. **Typography**: Update font imports in CSS files
3. **Animations**: Extend keyframes in Tailwind config
4. **Content**: Update component data/props
